# Product Roadmap — Living Architecture Nodes for VS Code

## Current stable — 0.1.0

- Workspace scan
- Architecture-memory health score
- Missing node detection
- Dirty/stale node detection
- Orphan node detection
- Generate missing node files
- Quick links to `ARCH.md`, `NERVE.md`, and `CHANGELOG.node.md`
- Local AI/dev handoff export bundle

## Controlled pre-release — 0.1.1

Purpose: validate the commercial product boundary and release path without prematurely enabling paid capabilities.

- Marketplace listing refresh
- Privacy/support/licensing refresh
- Free-tier product status boundary
- Workspace Trust limited-mode support
- Workspace-confined write/export authority
- Generated-node draft semantics
- Signed-entitlement consumer boundary
- Release/listing manifest and deterministic preflight
- Actual VSIX artifact inspection

## Stable target — 0.2.0

Stable promotion is blocked until all of these are verified:

- production entitlement service
- production public entitlement verification key
- approved Stripe Pro/Team product and price configuration
- checkout, Customer Portal, webhook, cancellation, downgrade, and offline entitlement behavior
- Marketplace pre-release installation/upgrade validation
- final VSIX security/leak audit
- synchronized listing, pricing, privacy, support, license, and changelog

## Product capability direction

Free remains useful and account-optional.

Candidate paid verification depth includes:

- semantic architectural drift
- change-impact and blast-radius analysis
- regression-memory correlation
- historical architecture comparison
- signed verification receipts
- richer AI/dev handoff evidence
- Team policy controls
- cross-repository architecture relationships

A paid tier may increase verification depth. It must never turn an unexecuted check into a false failure or safety verdict.
